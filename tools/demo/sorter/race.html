Each round dispatches nine requests without awaiting responses: four ANE, four MLX, and one explicit Jev API call, all using the same headline and question. The local backends use the same multilingual checkpoint; Jev uses its hosted model. Browser connection limits and the server's shared admission limit can reduce actual concurrency. No requests are retried. Rows always identify the requested backend. Every response marker stays on its requesting row; its color identifies the actual answerer: blue ANE, teal MLX, amber API (Jev). Native answers are solid. Redirects are hollow with a destination arrow: a teal →MLX ring on ANE means sent to ANE, answered by MLX. Local-to-Jev escalation is an amber →API ring on that local request row. Non-native same-backend replies are also hollow and excluded from stats. Wrong answers retain backend-colored markers with red labels, row flashes and bin borders. All lanes share one linear server-ms scale whose maximum is the slowest valid server latency observed in the session, including redirected and wrong answers. The maximum only grows, never shrinks between rounds, and resets only with R or a page reload. Pending elapsed time, errors and stale replies cannot change it. Labels use response arrival order within each request row. Busy and error results have no timed marker. The large number is elapsed time while that row's requests are pending. Once settled, local rows show their request batch's server span: maximum minus minimum server latency, including redirects, unavailable with fewer than two receipts. API shows the latency of its one requested call, whoever answered. Connectors originate on request rows and bin colors identify actual answerers once that request batch settles. Local score and p50 remain native-only on the multilingual checkpoint. API score and p50 include only its direct answers. Redirects, fallback and escalation are excluded from all stats. Scores count correct answers, with four opportunities per local row and one for API each round. Space pauses new rounds and activity motion; in-flight calls continue. R resets the session and ignores stale replies.
