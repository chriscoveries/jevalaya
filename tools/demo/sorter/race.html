Each round dispatches nine requests without awaiting responses: four ANE, four MLX, and one explicit Jev API call, all using the same headline and question. The local backends use the same multilingual checkpoint; Jev uses its hosted model. Browser connection limits and the server's shared admission limit can reduce actual concurrency. No requests are retried. Rows and colors always identify the requested backend: blue ANE, teal MLX, amber API (Jev). Every response marker, label, leader and connector keeps its requesting row's hue, regardless of who answers. Native answers are solid. Redirects are hollow with a destination arrow: a blue →MLX ring on ANE means sent to ANE, answered by MLX. Local-to-Jev escalation is a hollow ring in that local row's color labeled →API, never an amber local marker. Non-native same-backend replies are also hollow and excluded from stats. Wrong answers keep the row's hue and are labeled wrong; the row pulses in its own color and the category bin has a red border. All lanes share one linear server-ms scale whose right endpoint is the slowest valid server latency observed in the session, including redirected and wrong answers. That numeric maximum is labeled at the right end of every axis. The maximum only grows, never shrinks between rounds, and resets only with R or a page reload. Pending elapsed time, errors and stale replies cannot change it. Labels use response arrival order within each request row. Busy and error results are gray and have no timed marker. The large number is elapsed time while that row's requests are pending. Once settled, local rows show their request batch's server span: maximum minus minimum server latency, including redirects, unavailable with fewer than two receipts. API shows the latency of its one requested call, whoever answered. Connectors originate on request rows in their row's color; bin colors identify actual answerers once that request batch settles. Local score and p50 remain native-only on the multilingual checkpoint. API score and p50 include only its direct answers. Redirects, fallback and escalation are excluded from all stats. Scores count correct answers, with four opportunities per local row and one for API each round. Space pauses new rounds and activity motion; in-flight calls continue. R resets the session and ignores stale replies.
